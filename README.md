# Cassandra AI — Fraud & Mule-Network Detection Prototype

A thin, end-to-end prototype for ranking ATM/POS terminals by mule-network
withdrawal risk in 2-hour windows: a seeded simulator generates transactions and
mule account chains over a real geographic universe, a feature pipeline builds a
leak-free rolling-origin evaluation set, an XGBoost model ranks terminals with
SHAP explanations, and a FastAPI + React/MapLibre app surfaces the result as an
officer alert view.

See [PROTOTYPE_REPORT.md](PROTOTYPE_REPORT.md) for the full write-up: what was
built, data sources, model results, limitations, and reproduction steps.

## Setup

```bash
python -m venv .venv
./.venv/Scripts/pip install -r requirements.txt   # Windows
# or: ./.venv/bin/pip install -r requirements.txt  # macOS/Linux

cp .env.example .env
```

Requires Python 3.11 (some ML dependencies may not have prebuilt wheels on
much newer interpreter versions).

### Optional: Postgres/PostGIS

A `docker/docker-compose.yml` provisions Postgres with PostGIS for the
originally planned storage layer. It is **not required** to run the demo below
— the current pipeline reads and writes Parquet files directly.

```bash
cd docker && docker compose up -d
```

## Run the full demo

```bash
./scripts/run_demo.sh
```

This regenerates calibration data, simulated transactions (3 configurations),
features, trains the model, runs evaluation, and starts the API (port 8000)
and UI (port 5173). Takes a few minutes end to end.

## Results summary

The model does not currently beat a simple frequency baseline on this
simulated data (ROC AUC 0.39-0.58, confirmed across 5 random seeds) — reported
plainly rather than hidden. See [PROTOTYPE_REPORT.md](PROTOTYPE_REPORT.md) for
the full metrics, the independent leakage audit, real-data benchmark results,
and honest limitations.

## Data not included in this repository

Large or regenerable data files are excluded from version control (see
`.gitignore`) and are reproduced by the scripts above instead:

- `data/raw/` — frozen OpenStreetMap and Chicago Crimes API responses (fetched
  by `scripts/fetch_calibration.py` and `model/benchmarks/fetch_chicago_crimes.py`)
- `data/simulated/`, `data/processed/` — simulator and feature-pipeline output
  (regenerated by `simulator/generate.py` and `model/features.py`)
- `model/artifacts/*.json` — trained model files (regenerated by `model/train.py`)

Small, hand-transcribed calibration CSVs under `data/calibration/` (public NCRP
and RBI figures, with sources cited in `data/calibration/manifest.json`) are
included directly since they are small and clearly sourced.

## Repository layout

- `simulator/` — seeded transaction/account/complaint generator, 3 configurations
- `model/` — feature engineering, ST-DBSCAN, XGBoost + SHAP, baselines, evaluation
- `api/` — FastAPI backend
- `ui/` — React + MapLibre frontend
- `data/calibration/` — real public calibration data (OSM terminals, NCRP/RBI figures)
- `docs/` — data schema reference
- `results/` — metrics, benchmark notes, verification audit, screenshots
- `scripts/` — data-fetch and demo-run scripts
- `docker/` — Postgres/PostGIS provisioning (optional, not in the current read path)
